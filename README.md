# Make the AI Judge Laugh — Office Joke Entry

Entry for the [Make the AI Judge Laugh](https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225) bounty on make.fun.

`main.py` (pure Python standard library, no third-party packages, no network)
writes one original single-line joke about office life to `/output/entry.txt`:

> Our team held a meeting to decide if we needed a meeting, and the verdict was a recurring invite — indecision now has a calendar slot.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The joke is 134 characters, one line, plain UTF-8 text.
